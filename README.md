# LensVault

LensVault is a clean, responsive image exploration web app designed to let users quick-search and browse high-quality media. 

### Design Decisions
1. **Quick-Pick Category Chips:** Added visual category tags so users can explore popular themes with a single click.
2. **Slate/Teal Dark Mode Palette:** Selected a dark slate background (`#0f172a`) paired with a teal accent color (`#0d9488`) to deliver a modern, high-contrast visual experience.
